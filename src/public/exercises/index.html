    2. 
            
  2. Erstellen Sie einen Ordner content/ und legen Sie die Datei dort ab
    3. 
            
  3. Laden Sie die h5p.json Manifest-Datei herunter
    4. 
            
  4. Laden Sie die benötigten H5P-Bibliotheken von h5p.org herunter
    5. 
            
  5. Packen Sie alles als ZIP-Datei und benennen Sie sie in .h5p um
    6.
